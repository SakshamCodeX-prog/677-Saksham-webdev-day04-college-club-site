# Campus Connect – Coding Club

![Campus Connect Website Screenshot](https://github.com/user-attachments/assets/e120a9f5-cee6-4162-83b8-92d057eac72b)

A responsive four-page college club website created for the Coding Club at Invertis University, Bareilly. This project is built using HTML and CSS.

## Pages

- `index.html` — Coding Club introduction and calls to action.
- `about.html` — Club information, activities, and events.
- `registration.html` — Student registration form and volunteer application.
- `contact.html` — Club contact details and message form.

All four pages use the same navigation, responsive stylesheet, page metadata, and SVG favicon.

## Preview the Website

Open `index.html` in a web browser to view the website.

The forms demonstrate native HTML validation. The `action="#"` placeholders do not send submissions to a server. A form service or backend is required to receive submissions.

## Project Features

1. Responsive website design.
2. Four connected HTML pages.
3. Student registration form.
